# Souvenir Kvytok

Цей продукт створений виключно в навчальних та демонстраційних цілях. Він не є офіційним квитком на проїзд і не має жодної юридичної сили.

Автори не несуть жодної відповідальності за будь-яке використання цього продукту в незаконних або шахрайських цілях. Уся відповідальність за неправомірне використання покладається виключно на користувача.
